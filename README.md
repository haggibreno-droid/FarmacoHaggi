# FarmacoHaggi

Plataforma de estudos de Farmacologia aplicada à Enfermagem.

## Tecnologias

- React
- TypeScript
- Vite
- Lucide React

## Executar localmente

É necessário ter Node.js instalado.

```bash
npm install
npm run dev
```

Para verificar a versão de produção localmente:

```bash
npm run build
npm run preview
```

## Estado atual

A interface inicial contém uma página de boas-vindas, navegação visual, busca nos temas e cartões de trilhas de aprendizagem. O conteúdo e o progresso são demonstrativos nesta etapa; ainda não há login, banco de dados ou deploy configurado.

Projeto de estudo criado por Haggi.
